# Como contribuir — Mapa 1746

Obrigado pelo interesse. Este repositório é público: qualquer pessoa pode sugerir uma melhoria ou apontar um erro no mapa.

## Sugerir algo ou apontar um erro no mapa

1. Abra a aba **Issues** e clique em **New issue**.
2. Escolha o formulário que mais se parece com o seu caso:
   - **Pedido de ferramenta**, para uma ideia nova.
   - **Defeito numa ferramenta**, para um erro no mapa ou num número.
3. Descreva o que viu, onde (rua ou região) e o que esperava ver.

Falha de segurança não vai em issue: siga o [`SECURITY.md`](SECURITY.md).

## Regras que valem em tudo (issue, pull request e commit)

- **Ferramenta cívica e neutra.** Sem conteúdo político-partidário: nada de candidato, partido, campanha ou propaganda.
- **Só dado público e agregado.** O mapa mostra totais por rua ou por quadrado de cerca de 100 m, nunca um chamado sozinho.
- **Nunca publique:**
  - chamado individual (número, data e local de um chamado só);
  - coordenada exata de um chamado;
  - dado pessoal (nome, telefone, e-mail, endereço de quem chamou);
  - senha, token, chave de API ou qualquer outra credencial.

Se você publicou algo disso sem querer, avise na própria issue, sem repetir o conteúdo, e apague o trecho.

## Pull request de quem é de fora

- Pull request é bem-vindo, de preferência ligado a uma issue já aberta.
- A conferência automática (CI) de um pull request de fora só roda depois de aprovada por um responsável. Isso evita que código desconhecido rode no GitHub do projeto.
- O merge só acontece com o CI verde e a revisão de um responsável.
